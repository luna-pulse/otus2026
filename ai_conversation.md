# Контекст разговора (ai_conversation)

Сессия в Cursor по проекту `vasileva.QA` — мини-анкета (Go API + React).

## Хронология запросов и действий

1. **Создать сайт по заданию** (`task.md` / ранее `manager_task.md`): простое приложение без лишних вопросов; план → реализация → сборка → запуск.
   - Сделано: backend Go (`GET /questions`, `POST /answers`, память), frontend React/Vite, Docker (два образа + compose), README.
   - Запуск локально: API `:8080`, сайт `:8081`.

2. **Заменить тексты на фронте**
   - Подзаголовок → «Пять веселых вопросов»
   - Правки вопросов 3–4; вопрос 5 заменён на новый про Wi‑Fi
   - Справа от «Мини-анкета»: «Исполнитель: Васильева, Ольга. 2026»

3. **Убрать запятую** в строке исполнителя → «Васильева Ольга»

4. **Остановить приложение** и все связанные процессы (survey-api, Vite/node/esbuild). Порты 8080/8081 освобождены.

5. **Краткая инструкция запуска** для другого человека → файл `ЗАПУСК.md` (затем переименован в `launchdoc.md`).

6. **Swagger, документы, иконки**
   - Swagger на backend `:8080`, редирект `/` → `/swagger/`
   - Переименованы: `ЗАПУСК.md` → `launchdoc.md`, `manager_task.md` → `task.md`
   - Анкета в корне `http://localhost:8081/`
   - Три иконки справа на фронте → `/api/task`, `/api/launch`, `/api/promts`
   - Backend отдаёт markdown; Vite/nginx проксируют `/api` на backend
   - Создан файл контекста разговора (изначально `mypromt.md`) с оценкой токенов (4 типа)

7. **Переименование файла контекста**
   - `mypromt.md` → `ai_conversation.md`
   - Обновлён этот файл (добавлена запись о переименовании)
   - На backend относительный путь файла изменён: `serveDoc("mypromt.md")` → `serveDoc("ai_conversation.md")`
   - Маршрут API без изменений: `GET /api/promts` по-прежнему отдаёт этот файл
   - Обновлены Dockerfile, OpenAPI, README, launchdoc, подпись иконки на фронте
