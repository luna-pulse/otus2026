Роль: Ты - агент оркестратор.
Задача:
	необходимо сгенерировать и собрать простое приложение «Мини-анкета», состоящее из backend-части и небольшого frontend-интерфейса.
	Писать инструкцию по запуску приложения.
Контекст:
	Требуемый функционал
	Backend предоставляет два API:
	GET /questions — возвращает список вопросов анкеты (жёстко заданных, 5 шт.).
	POST /answers — принимает ответы пользователя и сохраняет их в памяти .
	Frontend:
	загружает вопросы с backend;
	отображает их в HTML/JS интерфейсе;
	отправляет заполненные ответы через POST /answers;
	показывает пользователю сообщение «Спасибо!» после отправки.
Ограничения. 
	Не создавай и не подключай базу данных.
	Один порт 8080 для бек апи, и другой порт 8081 для  фронт сайта.
Требования общие:
	Проект должен собираться в Докер контейнер. Два штуки Бэк и фронт.
	В одном солюшене должно быть два проекта. Один бэкэкэнд, второй фронтэнд.
	Аутентификацию и авторизацию не делаем. Чувствительных данных в проекте не будет.
Требования на Бекенд:
	Backend:  Go (version go1.26.5 windows/amd64), Приложение простое, можно минимал аппи.
	Оба Апи метода должны использовать одну и ту же модель для вопросов и ответов. Модель должна храниться в памяти приложения в рантайме в array.
	Этот массив должен быть доступен из любого потока - Для любого пользователя, без блокировок по тредам.
	Модель представляет из себя список вопросов и ответов,  Где есть нумерация вопроса, строка вопроса, строка ответа, более вызначение отвечен ли на вопрос.
Требования на Фронт: 
	Frontend:  React. Доступная версия
	Все вопросы являются необязательными. Вопросы придумай самостоятельно краткие, общие, смешные. 
	Ответ должен писать пользователь. Длина ответа не может быть больше пятьсот двенадцати символов.
	При перезагрузке страницы фронта подтягиваются данные из ответов и заполняются ответы, если они есть. 
	Если ответ нет, то строка ответа обычная. Если ответ есть, он заполняется и выделяется розовой очень тоненькой жирной солид рамочкой.
Результат. Цель:
	создать минимальное full-stack приложение (backend + frontend) с помощью AI-ассистента в IDE;
	настроить API для получения конфигурации анкеты и отправки ответов;
	развернуть фронтенд, подключенный к backend API;
	реализовать хранение пользовательских ответов в памяти backend-приложения;
